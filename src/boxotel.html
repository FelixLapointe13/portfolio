Étapes:

1 — Analyse des différentes parties de la maquette sur Figma

Pour commencer, mon partenaire et moi avons analysés et décortiqués la maquette de Boxotel pour définir les sections des pages et les composantes nécessaires.

2 — Intégration HTML du site d'hôtel avec VS Code

Suite à notre analyse, nous concevons avec du code HTML les pages du site tout en gardant une bonne organisation des sections et des classes.

3 — Ajout du CSS aux sections et aux classes dans VS Code

Dès que nous avons fini avec l'HTML, nous poursuivons le progrès en stylisant avec le CSS les quatre pages du site de Boxotel.

4 — Programmation JS et ajustement responsive du site sur VS Code

À la suite des styles, nous poursuivons la refonte du site en ajoutant les composantes JS appropriées et en rendant nos pages responsive.

5 - Résultat final de Boxotel via le navigateur au choix

Maintenant que c’est tout finalisé, nous pouvons explorer le site sur un navigateur pour voir les types de chambres, les bonus de l'espace détente et les détails d'une chambre.
